# Instance Segmentation

# Overview
This project demonstrates my ability to annotate individual objects using bounding box, polygon segmentation or
Brush or Mask Annotation. Unlike object detection, instance segmentation outlines the exact shape of each object
instead of using rectangular bounding boxes.

# Task
The goal of this project is to accurately identify and segment each object in an image using bounding box,
polygon segmentation or Brush or Mask Annotation.

# Skills Demonstrated
- Instance Segmentation
- bounding box
- Brush or Mask Annotation.
- Polygon Annotation
- Attention to Detail
- Following Annotation Guidelines
- Data Quality
