# Annotation Guidelines

# Purpose
The purpose of this project is to identify objects in images and annotate them using bounding boxes.

# Annotation Rules

# Car
Draw a bounding box tightly around the entire vehicle.

# Person
Draw a bounding box around the entire visible body of the person.

# Bicycle
Draw a bounding box around the complete bicycle.

# Dog
Draw a bounding box around the dog's entire body.

# Traffic Light
Draw a bounding box around the traffic light only.

# Tree
Draw a bounding box around the visible part of the tree.

# General Rules
- Draw the bounding box as close to the object as possible.
- Do not include large areas of the background.
- If an object is partially hidden, annotate only the visible portion.
- Ignore objects that are too small to identify confidently.
