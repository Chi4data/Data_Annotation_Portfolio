# Project Summary

# About This Project
This project demonstrates my ability to perform object detection by identifying and annotating objects in images
using bounding boxes.

# What I Learned
- How object detection is used to train AI models.
- How to draw accurate bounding boxes.
- How to follow image annotation guidelines.
- How to document image annotation projects professionally.

# Challenges
Some objects may overlap or be partially hidden, making it important to draw accurate bounding boxes
around only the visible portions.
