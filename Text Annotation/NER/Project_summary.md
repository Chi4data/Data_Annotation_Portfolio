# Project Summary

# About This Project
This project demonstrates my ability to identify, and label **Named Entities** in text. I annotated different types of
entities, including people, organizations, locations, dates, money, email addresses, and phone numbers.

# What I Learned
- How to identify **Named Entities** accurately.
- How to distinguish between different entity types.
- How to follow annotation guidelines consistently.
- How to document annotation decisions clearly.

# Challenges
Some entities can be difficult to classify because they may refer to different things depending on the context.
Following the annotation guidelines helped me make consistent labeling decisions.

# Skills Demonstrated
- Named Entity Recognition (NER)
- Text Annotation
- Data Labeling
- Attention to Detail
- Annotation Guidelines
- Data Documentation
