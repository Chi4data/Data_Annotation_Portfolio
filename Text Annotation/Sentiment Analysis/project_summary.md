Project Summary

About This Project

This project helped me practice sentiment annotation by classifying text into Positive, Negative, and Neutral categories.

What I Learned

- How to identify positive, negative, and neutral sentiments.
- How to apply annotation guidelines consistently.
- How to explain the reason for each annotation.
- How to handle texts that contain both positive and negative opinions.

Challenges

One of the biggest challenges was classifying text that contained mixed sentiments.
In such cases, I relied on the annotation guidelines and carefully explained the reason for my decision.

Skills Demonstrated

- Text Annotation
- Sentiment Analysis
- Attention to Detail
- Annotation Guidelines
- Data Documentation
