# Project Summary

# About This Project
This project demonstrates my ability to classify customer support messages into predefined categories by following
annotation guidelines and applying consistent labeling decisions.

# What I Learned
- How to classify customer support messages accurately.
- How to identify the primary intent of a message.
- How to apply annotation guidelines consistently.
- How to explain annotation decisions clearly.

# Challenges
Some customer messages contained more than one issue, making it important to identify the customer's primary request
before assigning a category.

# Skills Demonstrated
- Text Classification
- Text Annotation
- Intent Classification
- Attention to Detail
- Annotation Guidelines
- Data Documentation
