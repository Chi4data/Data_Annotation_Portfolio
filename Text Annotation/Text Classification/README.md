# Text Classification


# Project Overview
This project demonstrates my ability to classify text into predefined categories by following annotation guidelines. Text Classification is the broad task of assigning predefined categories, tags, or topics to entire documents, paragraphs, or chunks of text. It is widely used to organize customer messages, emails, support tickets, and other text data

# Project Objective
The objective of this project is to practice assigning the correct category to text based on its meaning while maintaining consistency and accuracy throughout the annotation process.
